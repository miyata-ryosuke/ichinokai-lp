# 画像の置き方

このフォルダに、下記のファイル名で画像を保存すると、LPに自動で表示されます。
（ファイル名はこのとおりにしてください。無い画像はプレースホルダ表示のままになります）

| ファイル名 | 使う場所 | 内容 |
|---|---|---|
| `awaji-sea.jpg` | 「なぜ淡路島」セクション | 淡路島の海・空の写真（横長推奨） |
| `gifted-code.png` | GIFTED CODE® セクション | GIFTED CODE® 人体図 |
| `kotan-sign.jpg` | 会場セクション（大） | 古淡 KOTAN の看板写真 |
| `lounge.jpg` | 会場セクション | ラウンジ（室内）の写真 |
| `practice.jpg` | 会場セクション | 人が押している姿／ワークの写真 |

## 差し替え方
1. 画像をこのフォルダ（`images/`）にコピー
2. 上の表のファイル名にリネーム
3. ブラウザを再読み込み

拡張子を変えたい場合（例：jpg → png）は、`index.html` の `data-img="images/..."` の記述も合わせて変更してください。
